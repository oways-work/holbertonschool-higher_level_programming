# Python - Everything is object

## Description
This project is part of the Higher Level Programming curriculum. It focuses on understanding how Python handles objects, memory allocation, and the difference between mutable and immutable types. By exploring identity vs. value, we learn how Python manages variables under the hood.

## Learning Objectives
* Why Python programming is awesome
* What is an object
* The difference between a mutable and an immutable object
* What is a reference
* What is an alias
* How to know if two variables are identical (identity)
* How to know if two variables are equal (value)
* How Python handles small integers and string interning

## Requirements
* **Allowed editors:** `vi`, `vim`, `emacs`
* **Environment:** All files interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
* **Style:** All Python code must use `pycodestyle` (version 2.7.*)
* **Formatting:** All files must end with a new line.
